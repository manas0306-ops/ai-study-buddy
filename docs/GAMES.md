# 10 Learning Games — AI Study Buddy

Learning is most effective when combined with play. AI Study Buddy features 10 educational arcade games:

1. **Code Rush**: Rapid-fire trivia against a countdown clock. Correct answers build streak score multipliers.
2. **Bug Hunter**: Real-world buggy code snippets. Identify the exact line or syntax bug to exterminate it.
3. **Output Predictor**: Mentally trace code execution and predict stdout without compiling.
4. **Memory Match**: Tile-flipping game pairing CS concepts to definitions in minimal turns.
5. **Flashcard Battle**: High-intensity flashcard gauntlet with combo multipliers.
6. **Algorithm Maze**: Dungeon exploration where unlocking doors requires solving CS challenges.
7. **Typing Code**: Measures syntax muscle memory, Words Per Minute (WPM), and typing accuracy on real code snippets.
8. **Binary Battle**: Number-system conversion race against an accelerating timer (Binary, Octal, Hex, Decimal).
9. **SQL Detective**: Murder mystery at Silicon Manor. Query suspect alibis and access logs to find the culprit.
10. **AI Quiz Boss**: RPG boss battle with HP bars. Correct answers deal critical damage; mistakes damage your shields!
