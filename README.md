# ai-study-buddy
An AI-powered study buddy that generates flashcards, quizzes, and bilingual explanations for programming concepts.

## 🚀 Features
- Generate flashcards for programming topics
- Create quizzes for self-assessment
- Provide bilingual explanations (e.g., English + Hindi)
- Easy-to-use Python script
